# Hierarchical Cross-Modal Attention Network (HCAN) for Physiological-Acoustic Multimodal Emotion Recognition

## Overview
This project presents a Hierarchical Cross-Modal Attention Network (HCAN) for multimodal emotion recognition using physiological and acoustic signals.

The framework combines:
- EEG-based physiological signals
- Speech-based acoustic features
- Graph Neural Networks (GNNs)
- Transformer-based temporal modeling
- Bidirectional Cross-Modal Attention

The proposed architecture is evaluated on:
- SEED-IV Dataset
- RAVDESS Dataset

## Key Features
- EEG signal preprocessing
- Speech feature extraction
- Multimodal feature fusion
- Cross-modal attention mechanism
- Emotion classification pipeline
